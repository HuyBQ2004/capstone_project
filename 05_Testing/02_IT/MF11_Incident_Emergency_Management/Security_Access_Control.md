# Integration Test Case — Security & Access Control (MF11 Incident & Emergency Management)

## Feature: System Security & Access Control

### 1. General Information

| Field | Value |
|---|---|
| Feature | System Security & Access Control |
| Test requirement | Verify the full 7-role × endpoint RBAC matrix (BR-007) across MF11's write and read surface, including direct API calls that bypass UI-hidden buttons and disabled controls (CF-M11-9); verify that health-data fields (`symptoms`, `clinicalRiskAssessment`, lab results, student identity) are cut at the server-side response-projection layer according to caller role — never filtered client-side — for Service Caterers, Teacher, and Parent scopes; verify actor identity and resource scope are always derived from the JWT, never from client-supplied body/query fields, with out-of-scope resources returning 403 (never 404) to avoid leaking the existence of child health records; and verify rate limiting on high-risk endpoints plus BR-170/BR-188 immutable, IP-stamped audit trails for every violation-record operation. |
| Number of TCs | 16 |
