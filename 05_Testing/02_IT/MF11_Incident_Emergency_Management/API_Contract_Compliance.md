### 1. General Information

| Field | Value |
|---|---|
| Feature | API Contract Compliance (OpenAPI `/v3/api-docs`) |
| Test requirement | Verify `/v3/api-docs` (convention **D8**, rules S1–S8) accurately reflects the MF11 contract: S1/S2 `@Tag`/`description` traceability to UC + BR IDs; S3 every 4xx/5xx `$ref`s the shared `ErrorResponse` and matches TDS §10 1-to-1; S4/S6 ISO date/date-time formats and business-code `id` examples (no UUID leak); S5/S7 real enum types (no hand-written `allowableValues`) matching the D6 value sets, and `PagedResponse<T>` shape on all list `GET`s; S8 + forbidden API surface (no `release`/`unlock`-style endpoints, no client-supplied `id`, no `staffName`/`staffPosition`/`disciplinaryLevel` fields, no foreign-module paths); and **D11** role-dependent `oneOf` response shape for `GET /incidents` (Medical Staff vs. Service Caterers vs. Teacher field-set differences). |
