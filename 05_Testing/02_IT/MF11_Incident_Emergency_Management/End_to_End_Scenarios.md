# Integration Test Case — End-to-End Scenarios (MF11 Incident & Emergency Management)

---

## Feature: End-to-End Scenarios

### 1. General Information

| Field | Value |
|---|---|
| Feature | End-to-End Scenarios |
| Test requirement | Verify the complete cross-module incident-management spine — source report → incident record → investigation (severity, quarantine, traceability, root cause) → corrective action plan (CAPA) → closure — executed end-to-end by the correct sequence of actors. Verify role-based data isolation (PII and clinical/health data) when multiple roles read the same incident record, the 3-independent-gate closure readiness check (CAPA completion, student recovery, batch final state), the full violation-record lifecycle including its PDF/signed-record gate, the `reportExported` read-only lock that blocks all write endpoints for every role except `close`, and FE↔BE contract compatibility when the FE `baseURL` is pointed at the real backend. |
| Number of TCs | 6 |
