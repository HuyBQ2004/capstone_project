## Feature: Audit Log & Error Log Query (UC-106 / UC-111)

### 1. General Information

| Field | Value |
|---|---|
| Feature | Audit Log & Error Log Query |
| Test requirement | Verify audit-log immutability at the data layer (hash chain `prev_hash → entry_hash`, `GET /audit-logs/integrity`), that no write route exists for `/audit-logs*` (405), the shared pagination contract (5 keys, page/pageSize clamping) applied to `audit-logs`/`error-logs`, that `GET /error-logs` returns full `stackTrace`+`sessionInfo` in the list view (C14), the `audit-logs` filter contract (`ip`, `dateFrom`/`dateTo`, `search` restricted to `SEARCH_FIELDS`), and that every MF12 write operation produces an audit row with non-null `actor`/`ip`/`resource`/`timestamp` (BR-170, BR-177). |
| Number of TCs | 8 |
