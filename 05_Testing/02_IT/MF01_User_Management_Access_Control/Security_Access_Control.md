## Feature: `System Security & Access Control`

### 1. General Information

| Field | Value |
|---|---|
| Feature | System Security & Access Control |
| Test requirement | Verify the authorization layer end to end: the full RBAC matrix of 7 roles against 12 endpoint groups, rejection of unauthenticated calls, access token lifetime driven by the security policy, resistance to JWT forgery, identity taken strictly from the JWT rather than from the request payload, and protection of the primary System Admin account. |
