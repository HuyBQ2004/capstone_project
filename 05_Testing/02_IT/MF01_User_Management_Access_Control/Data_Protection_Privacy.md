# Integration Test Case — Data Protection & Privacy (MF01 User Management & Access Control)

---

## Feature: `Tenant Isolation, Data Privacy & Injection Defence`

### 1. General Information

| Field | Value |
|---|---|
| Feature | Tenant Isolation, Data Privacy & Injection Defence |
| Test requirement | Verify that data never crosses a tenant boundary by `schoolId` or `partnerId`, that a refresh token is unusable through all seven revocation paths, that no response or log line leaks a credential, that account existence is never disclosed through authentication or recovery endpoints, and that the Google sign-in flow and the search and write endpoints resist injection and abuse. |
| Number of TCs | 49 |
