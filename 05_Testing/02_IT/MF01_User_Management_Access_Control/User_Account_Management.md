# Integration Test Case — User Account Management (MF01 User Management & Access Control)

## Feature: `User Account Management`

### 1. General Information

| Field | Value |
|---|---|
| Feature | User Account Management |
| Test requirement | Verify the user lifecycle endpoints end to end: account creation with a server-determined status and duplicate-email protection, activation from a token, status toggling with immediate session revocation, the five-field pagination contract with filtering and search, the event-driven cascade when a partner is suspended, and the standard 404 and 422 error envelopes. |
| Number of TCs | 40 |
