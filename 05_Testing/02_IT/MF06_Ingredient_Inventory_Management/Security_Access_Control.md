## Feature: System Security & Access Control

### 1. General Information

| Field | Value |
|---|---|
| Feature | System Security & Access Control |
| Test requirement | Verify tenant/supplier isolation (cross-supplier and cross-school IDOR, BR-007), the full 7-role RBAC authorization matrix (TDS §16: System Admin, School Administration, Medical Staff, Teacher, Parent, Raw Food Supplier, Service Caterers), the JWT-always-wins scoping rule for `schoolId`/`supplierId` (never trusted from body/query), unauthenticated/expired/malformed token rejection, file-upload validation (type before size), server-authoritative timestamp/GPS/device on receiving, the "gate bypass" attack simulation covering all 8 hard business-rule gates when calling the API directly (bypassing the FE form, per CF-M06-12 — the highest-severity finding of the 2026-07-29 review), role-boundary edge cases (quarantine is Medical Staff-only, suppliers never see `/inventory`), the D11 role-based response-shape parity regression test, and the D10-BIS private-document access control for food-safety evidence photos and supplier certificates. |
| Number of TCs | 15 |
